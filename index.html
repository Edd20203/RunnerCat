🎮 CONTROLES Y PODERES

ESPACIO / ↑ / W Saltar (x2) en N1-N4, Nadar arriba (N5-N8) o Subir / Disparar (N9-N12)
↓ / S Agacharse (N1-N4), Sumergirse (N5-N8) o Bajar avión (N9-N12)
X / J / → / D Zarpazo / Lanzar Minas (N5-N8) / Disparar y Misiles (N9-N12) / Golpear Jefe (N4)
SHIFT / ← / A Ralentizar velocidad (mantener): activa cámara lenta consumiendo energía
P / ESC Pausar / Reanudar partida
